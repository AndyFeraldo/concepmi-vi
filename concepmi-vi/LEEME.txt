Herramientas (carpeta ../herramientas, NO se publica)
-----------------------------------------------------
node herramientas/servidor.js                                  Previsualizar en http://localhost:5173
node herramientas/procesar.js foto <entrada> <salida.jpg> [x,y,lado]   Foto cuadrada 600x600 comprimida
node herramientas/procesar.js logo <entrada> <salida.png>              Logo recortado, máx. 600x300
node herramientas/logos.js                                     Regenera logo CONCEPMI, logo del club y Wolfito
node herramientas/social.js                                    Regenera og-image.jpg y favicon.png
node herramientas/qr.js <enlace>                               Regenera el QR del grupo de WhatsApp
Para publicar se sube SOLO la carpeta concepmi-vi/.

Publicación (GitHub Pages)
--------------------------
Sitio:        https://andyferaldo.github.io/concepmi-vi/
Repositorio:  https://github.com/AndyFeraldo/concepmi-vi
Para publicar cambios (desde la carpeta PAGINA WEB):
  git add -A && git commit -m "Describe el cambio" && git push
  bash herramientas/publicar.sh "Describe el cambio"
(publicar.sh copia concepmi-vi/ encima de gh-pages sin borrar lo que ya esté publicado)
La página se actualiza en 1–2 minutos.

Equipo organizador: oculto mientras faltan fotos. Para mostrarlo, en index.html cambia mostrarEquipo: false → true.
concurso-conocimientos/: sistema en vivo del Concurso de Conocimientos (creado en otra sesión).
